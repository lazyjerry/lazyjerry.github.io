# 時間窗重疊與跨期去重

## 觸發時機

- 篩選本期正式參考資料時
- 發現候選來源日期落在上一期報告的時間窗內時
- 覺得某則新聞「好像上次寫過」時

## 內容

週報每週發一次，但時間窗是 15 天，所以**每一期都有大約一半的窗期與上一期重疊**。純看日期是否落在窗內，會反覆選到同一批事件。

### 作法

1. 篩選正式來源前，先開上一期的 `tech/{上一期日期}/references.md`，把該期的來源網址列出來。
2. 候選來源若網址或事件與上期重複，即使日期落在本期窗內也淘汰，並在 `source.md` 註明「上一期已引用」。
3. 同一家來源的**不同事件**不算重複；例如上期用了某站 8/14 的公告，本期用該站 8/19、8/21 的另兩篇仍可。
4. 大型系列活動（例如發表週、藝術節）若上期已引用其中一場，本期不再引用同系列的其他場次，改找別的事件。

### 為什麼

參考資料表是讀者判斷「這期有沒有新東西」的依據。重複引用會讓連續兩期的參考資料看起來像同一份，也浪費本來就稀缺的窗內名額。

### 實務影響

窗期重疊也代表**每期真正的新事件只有約 7 天份**，所以醫療科技、房地產與室內外裝潢、現場表演藝術這類本來就稀疏的分類，要預留補搜輪次，不要等到最後才發現湊不齊。
