### 修正的來源與原因

- **ref-1（Anthropic）**：內文「18 個代理同搶一個檔案」為翻譯失真，原文為「30 個代理中有 18 個各自建立同名 git 分支」，屬分支撞名而非搶檔案。已修正 report.md 亮點／趨勢與 source.md 摘要。
- **ref-3（Cloudflare DDoS）**：以 WebFetch 對原文兩次獨立擷取，均查無「805 次集中在第二季」「90.6% 攻擊不到十分鐘」「最大流量僅維持 35 秒」三個數字依據。已從 report.md 與 source.md 移除，改用原文明確列出的 Q1→Q2 519% 增幅。
- **ref-7（癲癇睡眠研究）**：WebFetch 重新核對 TechNews 全文，確認文中未出現「動作記憶」「隔日」等時間限定詞，也未寫出樣本人數。「19 名患者」「動作記憶」「隔日」實為淘汰候選 D（PNAS 原論文，未列正式來源）的細節被誤植進 ref-7 段落，已修正為「記憶表現」「樣本規模有限」。
- **ref-11（Twitch AI 訓練）**：WebFetch 比對原文 HTML，確認納入生成式 AI 訓練的內容僅列「直播、精華片段、圖片、聊天室紀錄」四類，原文無「VOD（隨選影片）」「剪輯」字樣。已從 report.md 與 source.md 移除這兩項。
